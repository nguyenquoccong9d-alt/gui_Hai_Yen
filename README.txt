THIỆP HỒNG PASTEL - HƯỚNG DẪN

1. Mở file index.html để xem thiệp.
2. Để nhạc chạy, đặt 2 file MP3 cùng thư mục:
   dung-lam-trai-tim-anh-dau.mp3
   khong-thoi-gian.mp3

3. Nội dung cần sửa nằm ngay trong index.html, tại các dòng có:
   ✏️ BẠN VIẾT ...

4. Nếu muốn gửi cho điện thoại:
   - Có thể nén cả thư mục thành ZIP để lưu/chia sẻ.
   - Nếu muốn mở bằng một đường link trên điện thoại, tải index.html + 2 file MP3 lên GitHub Pages.
   - Lưu ý: trình duyệt điện thoại thường chặn autoplay, nên thiệp có nút "Mở thiệp" để người nhận chạm vào trước khi nhạc phát.

5. Bản này không nhúng sẵn các bài hát có bản quyền. Hãy dùng file âm thanh mà bạn có quyền sử dụng.
